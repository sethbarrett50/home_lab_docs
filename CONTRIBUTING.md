# Contributing

This is a personal homelab documentation repo, made public for
reproducibility and transparency around the network/infrastructure setup
used in ongoing dissertation research (see `docs/services/` for the research
service write-ups once added).

## If you're here for research reproducibility

Open a [question issue](../../issues/new?template=question.yml) if something
in the docs is unclear, inconsistent, or you're trying to reproduce a part of
the setup and hitting a gap. That's the most useful kind of contribution this
repo can get from outside readers.

## If you spot an error

Docs corrections are welcome via PR. Keep changes scoped and factual — this
repo documents one specific, real setup, not general best-practice guidance,
so PRs should reflect what's actually true of this infrastructure rather than
propose alternative architectures.

## Scope

This isn't a general-purpose homelab guide or a place for feature requests
about setups other than this one. Issues/PRs about the actual documented
infrastructure, its accuracy, or the research use case are in scope;
everything else probably isn't.
